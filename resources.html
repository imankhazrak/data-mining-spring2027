Set up R

  1. Install R (≥ 4.3), then RStudio Desktop.
  2. Run this once in the RStudio console:
R
install.packages(c("tidyverse", "caret", "glmnet", "rpart", "rpart.plot",
                   "nnet", "NeuralNetTools", "randomForest", "gbm", "pROC",
                   "gains", "arules", "arulesViz", "recommenderlab",
                   "rmarkdown", "knitr"))

Use an RStudio Project for the course and put the CSVs in a data/ folder inside it, so that read.csv("data/UniversalBank.csv") works for every lecture.

Set up Python

  1. Install Python ≥ 3.10 (or Miniconda), and VS Code with the Python and Jupyter extensions.
  2. Create an environment and install the packages:
Shell
python -m venv dm-env
source dm-env/bin/activate        # Windows: dm-env\Scripts\activate
pip install pandas numpy scikit-learn matplotlib seaborn statsmodels \
            imbalanced-learn mlxtend jupyter

The Python edition of the textbook also ships a helper package, dmba (pip install dmba), with the same datasets and plotting utilities.
