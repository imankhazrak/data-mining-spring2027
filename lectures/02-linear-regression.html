Linear Regression for Prediction

Linear regression is the workhorse you already know, used here with a different goal. We will fit it by least squares, read its coefficients correctly, and judge it by how well it predicts cars it has never seen.

~75 minTextbook ch. 6

Concept map

The model and two different goals

Multiple linear regression relates a numeric outcome to \(p\) predictors:

\[ Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \cdots + \beta_p X_p + \varepsilon \]

The same equation can serve two very different purposes, and the purpose decides what “good” means.

Explanatory modellingPredictive modelling (this course)
GoalUnderstand how X affects Y in the populationPredict Y accurately for new individual records
Data used for fitAll of itTraining set only; validation set held out
Judged byGoodness of fit, significance, assumptionsError on the validation set (RMSE, MAE)
MulticollinearityA serious problem (unstable β)Tolerable if predictions are accurate

Least squares, by hand and by algorithm

Ordinary least squares (OLS) chooses the coefficients \(\hat\beta\) that minimize the sum of squared residuals, where each residual is the gap between an actual and a fitted value:

\[ \text{SSE} = \sum_{i=1}^{n} (y_i - \hat y_i)^2, \qquad \hat\beta = (X^\top X)^{-1} X^\top y \]

Drag any point. Click empty space to add a point; Shift-click a point to remove it. Turn on “fit by hand” and try to get your SSE below the OLS line’s. You can’t: that is the definition of least squares.

Add one outlier far from the others at a very old age (top-right of the plot). What happens to the OLS line?

C. Squaring gives a point twice as far away four times the influence. A point that is extreme in X (high leverage) and far from the trend can drag the whole line. Try it in the demo. This is one reason we explore before modelling.

Fitting Price on ten predictors for 600 training cars gives coefficients like these (exact values depend on the random split):

A colleague says: “The Doors coefficient is negative, so adding a door to a car causes its value to drop.” Is that a valid conclusion?

A. “Holding others fixed” is a statement about the fitted equation, not about intervening in the world. Doors is correlated with body type, model and age in ways the model only partially captures. For prediction we don’t need causality; we just shouldn’t claim it.

Residuals and what to check

A residual \(e_i = y_i - \hat y_i\) is what the model got wrong. For predictive work we care less about textbook assumptions (normal errors, for instance) and more about patterns the model is missing:

  • Curvature in residuals vs. fitted values → add a transformed term (log, square) or use a more flexible model.
  • Fanning out (spread grows with fitted value) → try modelling \(\log(Y)\). Remember to back-transform predictions.
  • A few huge residuals → errors in the data, or a segment the model does not fit (e.g. luxury trims).
Key idea

Training-set R² and residual plots tell you about the fit. Whether the model predicts well is a separate question, answered on held-out data. That is next lecture’s topic, and we preview it in the code walk below.

Code walk: predicting used-car prices

Data: ToyotaCorolla.csv, first 1,000 cars.

Select predictors

car <- read.csv("data/ToyotaCorolla.csv")[1:1000, ]
preds <- c("Age_08_04", "KM", "Fuel_Type", "HP", "Met_Color", "Automatic",
           "CC", "Doors", "Quarterly_Tax", "Weight")
car <- car[, c("Price", preds)]
car$Fuel_Type <- factor(car$Fuel_Type)      # CNG is the reference level

import pandas as pd
car = pd.read_csv("data/ToyotaCorolla.csv").iloc[:1000]
preds = ["Age_08_04", "KM", "Fuel_Type", "HP", "Met_Color", "Automatic",
         "CC", "Doors", "Quarterly_Tax", "Weight"]
X = pd.get_dummies(car[preds], drop_first=True, dtype=int)   # CNG is the reference level
y = car["Price"]

Partition 60 / 40

set.seed(1)
train_idx <- sample(nrow(car), 0.6 * nrow(car))
train <- car[train_idx, ]
valid <- car[-train_idx, ]

from sklearn.model_selection import train_test_split
X_train, X_valid, y_train, y_valid = train_test_split(X, y, test_size=0.4, random_state=1)

Fit by least squares and read the output

fit <- lm(Price ~ ., data = train)
summary(fit)          # coefficients, std. errors, R-squared

from sklearn.linear_model import LinearRegression
fit = LinearRegression().fit(X_train, y_train)
print(pd.Series(fit.coef_, index=X.columns).round(3))
print("intercept", round(fit.intercept_, 1), " train R2", round(fit.score(X_train, y_train), 3))
What you should see: Age ≈ −140 per month, KM ≈ −0.018, HP ≈ +36, Petrol ≈ +2,300 vs. CNG; training R² ≈ 0.86. Your numbers will differ a little depending on the split.

Predict cars the model has not seen

pred <- predict(fit, newdata = valid)
err  <- valid$Price - pred
c(RMSE = sqrt(mean(err^2)), MAE = mean(abs(err)), MeanError = mean(err))
hist(err, breaks = 30, main = "Validation residuals")

import numpy as np
pred = fit.predict(X_valid)
err = y_valid - pred
print({"RMSE": np.sqrt((err**2).mean()), "MAE": err.abs().mean(), "MeanError": err.mean()})
err.plot.hist(bins=30, title="Validation residuals")
What you should see: validation RMSE ≈ €1,300–1,400 and MAE ≈ €1,000, with a mean error near 0 (no systematic bias). Price averages about €11,900, so typical errors are around 9–11%.

Common pitfalls

  • Reporting training R² as performance. It is always optimistic; report validation RMSE/MAE.
  • Extrapolating. The model knows cars 1–68 months old; don’t ask it about a brand-new car.
  • Forgetting the reference level. A dummy coefficient is always relative to the omitted category.
  • Causal language (“increasing HP will raise the price”) from observational data.
  • Mismatched categories. If the validation set has a level that is missing from training, prediction fails. Set factor levels on the full data before splitting.
