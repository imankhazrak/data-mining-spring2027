What is data mining?

Data mining is the set of tools, methods and theory for revealing patterns in data, and especially for using those patterns to make predictions about new cases. Most questions you will meet fall into one of five families:

Question typeExampleTypical methods
Predict a numberHow much will this customer spend next month?Linear regression, kNN, trees, neural nets
Predict a categoryWill this customer accept a loan offer: yes or no?Logistic regression, kNN, trees, ensembles
Find groupsWhat customer segments exist?Hierarchical clustering, k-means
What goes with whatPeople who buy X also buy …?Association rules, collaborative filtering
Spot the unusualIs this credit-card transaction fraud?Rare-event classification, anomaly detection

Data mining overlaps with statistics and machine learning. The difference is mostly in emphasis. Classical statistics often asks “what is the effect of X on Y, and how sure are we?” (explanation and inference). Data mining asks “how well can we predict Y for a record we have not seen yet?” (prediction). That shift changes how we judge a model: by its performance on new data, not by p-values on the data used to fit it.

A model fits its training data almost perfectly (R² = 0.99). What is the most important thing you still don’t know?

C. A near-perfect fit on training data is as consistent with memorising noise as with learning a real pattern. The only honest test of a predictive model is data it never saw. Lecture 3 builds this into every analysis with partitioning and cross-validation.

Supervised vs. unsupervised; regression vs. classification

Every dataset in this course has n records (rows) and p variables (columns). Two questions sort every method:

1 · Is there an outcome Y?

Supervised learning: yes. We have labelled examples and want to predict Y from predictors X₁…Xp.
Unsupervised learning: no. We look for structure (groups, associations) in X alone.

2 · If yes, what kind of Y?

Regression (prediction): Y is numeric, such as price, sales or blood pressure.
Classification: Y is categorical, such as buy/not buy, benign/malignant or one of several classes.

Terminology varies by field, so learn the synonyms. Predictors are also called features, inputs, independent variables, attributes or X. The outcome is also called the response, target, label, dependent variable or Y. A row is a record, observation, case or instance.

The data-mining process

Whatever the method, a project moves through the same steps. Most of the work, and most of the mistakes, happen before the model is fitted.

#StepWhat you actually do
1Define the purposeWho will use the result, for what decision? What would “good enough” look like?
2Obtain the dataPull records; for big data, sample. Ask how the data were collected and what is missing.
3Explore & cleanSummaries and plots; fix types; find errors, outliers and missing values.
4Reduce & transformCreate dummies, scale, combine categories, drop leaking or redundant variables (L6–L7).
5PartitionSplit into training / validation / test before modelling (L3).
6Choose & fit methodsTry several candidate models (L2, L4, L8–L11).
7Evaluate & compareJudge on held-out data with a metric that matches the purpose (L3, L5).
8Deploy & monitorScore new records; watch for drift as the world changes.
In the West Roxbury data, TAX (the property tax bill) has a correlation of 1.00 with TOTAL VALUE. You want to predict the value of homes that are about to be listed. Should TAX be a predictor?

B. This is leakage: a predictor that is really a re-expression of the outcome. The model would look superb in testing and be useless in practice. Step 1 (the purpose) tells you which variables are legitimately available at prediction time.

Data types and preprocessing

Numeric

Continuous (price, area) or integer counts (rooms). Watch scale: when predictors are measured in very different units, distance-based methods (kNN, clustering, neural nets) need standardization: \(z = (x - \bar x)/s\).

Categorical

Nominal (colour, fuel type) or ordinal (low/med/high). Most methods need them as dummy (indicator) variables: a variable with k levels becomes k − 1 0/1 columns in regression-type models.

REMODEL has three levels: None, Old and Recent. How many dummy variables does a linear regression need for it?

2. One level (say None) becomes the reference category, coded as zeros in both dummies. Including all three alongside an intercept gives perfect multicollinearity (the “dummy variable trap”), because the three columns always add up to 1.

Missing values and outliers

  • Missing: delete records (if few), impute (median, mode or a model), or add a “missing” indicator. Always ask why values are missing.
  • Outliers: some are data errors (a house “built” in year 0), others are real and important. Decide case by case, and write down what you did.
A real trap in this dataset

In West Roxbury, REMODEL uses the text None for “never remodelled”. R’s read.csv keeps it as a string, but pandas silently turns “None” into a missing value: 4,346 of 5,802 rows. Same file, different data! The code walk shows the fix.

Common pitfalls

  • Trusting the reader. Software guesses types and missing-value codes. Always check counts after loading (“None” → NaN in pandas).
  • Leaking the answer. Any variable computed from, or recorded after, the outcome must go (TAX here).
  • Coding categories as numbers. Codes like 1/2/3 for unordered categories make a model treat them as amounts. Use dummies.
  • Exploring the test set. Decisions made after looking at all of the data leak information too. From Lecture 3 on, explore the training data only.
  • Dropping outliers by reflex. A year of 0 is an error; a $1.2M house is real. Know the difference.

A hospital wants to predict whether a patient will be readmitted within 30 days. This is…
The outcome (readmitted: yes/no) is known for past patients and is categorical, so this is supervised classification.
A variable “Region” has 5 levels. How many dummy variables enter a linear regression with an intercept?
k − 1 = 4. The omitted level is the reference category absorbed by the intercept.
Which variable is most likely to cause leakage when predicting whether a loan will default?
Late-payment letters are only known after the outcome starts to unfold, so they wouldn’t be available when the decision is made.
Which chart best shows how home value differs between remodel groups?
Boxplots compare the centre, spread and outliers of a numeric variable across categories at a glance.
